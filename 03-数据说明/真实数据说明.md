# 真实数据说明（seed_real_data.py）

> 生成时间：2026-09-07 · 脚本位置：`smartlearn-backend/seed_real_data.py` · **幂等可重复执行 · SQLite/MySQL 双库自适应**

## 〇、数据库选择

脚本启动时按优先级解析连接：`DATABASE_URL` 环境变量 → `.env` 文件 → 默认 `sqlite:///./smartlearn.db`。
MySQL 模式自动处理方言差异（`INSERT OR IGNORE` → `INSERT IGNORE`、`?` 占位符 → 命名参数）。

```bash
# SQLite（默认）
python seed_real_data.py

# MySQL（.env 已指向 MySQL 或显式传变量）
DATABASE_URL=mysql+aiomysql://root:123456@127.0.0.1:3306/smartlearn python seed_real_data.py
```

## 一、设计原则

1. **真实性**：所有内容由真实教学场景构造（FastAPI 依赖注入答疑、快排基准退化、MVCC undo 链、TCP 三次握手……），不含占位文本；
2. **幂等性**：以内容指纹（标题全文/发送者+内容/日期+范围）判重，已有数据自动跳过，重复执行不会翻倍；
3. **覆盖度**：每个功能页面都有可展示的数据——讨论广场能翻页、考试列表三态齐全、消息中心有未读、签到名单有未签；
4. **一致性**：外键真实（作者是真实选课学生、阅卷人是任课教师、错题来自真实答题记录），计数同步（like_count = 实际点赞行数）。

## 二、数据全景

| 域 | 表 | 行数 | 关键内容 |
|---|---|---|---|
| 清理 | `question`/`exam_record` | -6 / -4 | 删除 `course_id IS NULL` 占位题与孤儿考试记录 |
| 题库 | `question` | 156 | 5 课程 ×（SINGLE 8-19/MULTI 3-5/JUDGE 6-8/BLANK 6-7/SHORT 3-5）× 难度 1-3 |
| 试卷 | `exam_paper` + `exam_paper_question` | 5 + 50 | 为 exam 1-3 补建试卷；新增 exam 4/5（计网/OS 单元测验） |
| 考试记录 | `exam_record` | 51 | 10 人/场 × 5 场，三档成绩画像（85±/68±/45±），12% 留 GRADING 态 |
| 答题明细 | `exam_answer` | 507 | 逐题作答 + 判分，客观题错题自动归集错题本 |
| 错题本 | `wrong_question` | 172 | 按人 × 题去重（联合主键），含 wrong_count 与 is_mastered |
| 课程讨论 | `discussion_post`/`reply`/`like` | 24/62/98 | 5 门课每课 3-4 帖（FastAPI/快排/EXPLAIN/拥塞控制/页面置换…） |
| 教研区 | 同上（course_id=0） | 5 帖 + 回复 | 下学期实验安排/期中难度分析/图算法教法/分组方式/大作业选题 |
| 私聊 | `chat_message` | 24 | 三类：学生→教师答疑（5 轮）、学生↔学生组队、教师↔教师教研 |
| 签到 | `sign_task`/`sign_record` | 25 / 231 | 近 3 天 × 5 课，每场 75%~100% 出勤（未签名单可查） |
| 通知 | `notification`/`_read` | 16 / 部分 | 5 类新增（课程更新/成绩/宣讲会/维护/新岗位），分角色投递 |
| 进度 | `progress` | 85 | 每人每课一行：已有进度自然推进 ≤100%，新课 15~95% |
| 统计 | `stat_daily_learning` | 281 | 近 14 天 USER 级（分钟/题数/正确率）+ COURSE 级（活跃度） |
| 反馈 | `feedback` | 11 | 五类（缺陷/建议/体验/纠错/其他）× 四状态（待处理 3/处理中 2/已解决 6/驳回 0），已解决的带管理员真实回复 |

## 三、枚举值对照（易错点）

SQLite 中该库的 `review_status`/`status` 存**数值**（ORM 枚举的 value）：

| 字段 | 值 | 含义 |
|---|---|---|
| `discussion_post.review_status` / `discussion_reply.review_status` | `1` | APPROVED（0 待审 / 2 驳回） |
| `discussion_post.status` | `1` | ACTIVE |
| `exam.status` | `0/1/2` | 未开考 / 进行中 / 已结束 |

> 脚本初版误插字符串 `'APPROVED'`，已修正为数值并全表 UPDATE 兜底。

## 六、模拟器端到端演示路径

1. **讨论广场分页**：学生端首页 → 课程讨论「讨论广场」→ 切 10 条/页 → 翻到第 2/3 页；
2. **教研区**：教师端「教研」→ 5 帖真实教研讨论（学生端无此入口且 API 403）；
3. **考试**：学生「考试」Tab → 5 场考试三态 → 已结束场查看成绩 + 逐题解析；
4. **签到**：教师授课页签到名单（未签学生可补签）；学生签到页近 3 天任务；
5. **消息**：学生消息 Tab 红点（未读通知 + 好友申请）；教师↔教师聊天记录。
