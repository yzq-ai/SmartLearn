## 四、数据与迁移

- 40 张表（`app/models/__init__.py`，六域），`Base.metadata` 单一来源。
- 三种建表一致：`init_db`（create_all）、`mysql/init/001_schema.sql`（自动生成）、Alembic `alembic upgrade head`。
- Celery：`app/tasks/`（worker/beat），eager 模式本地直跑，生产 Redis。
- Redis：限流 + 交卷分布式锁（未配置时优雅回退内存）。

## 六、已知限制

1. 端侧 ArkTS 未完成 HAP 安装与真机/模拟器 UI 验收（本机 Hvigor 命令行构建受 `pnpm` 安装阻塞、HDC 目标 Offline）。
2. Push Kit 推送、OBS 对象存储、RAG 向量库（Milvus/Qdrant）需外部服务/账号，未接入（已留规则兜底与接口边界）。
3. 端侧页面直连网络层，ViewModel/Repository 分层未做。
4. Celery 生产需 Redis broker；本地默认 eager 模式。
